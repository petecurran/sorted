# Decisions

Short records of the calls that shaped Sorted, each with what we decided, why, and what it costs. Sorted was built in a day for a demo, so each one says where it would change before real use.

| # | Decision |
|---|---|
| [1](0001-local-model.md) | The model runs on the council's own machine |
| [2](0002-model-reads-rules-decide.md) | The model reads the photo, and the council's rules decide |
| [3](0003-simulated-data.md) | Every report is simulated, and the council is made up |
| [4](0004-laptop-trust-rule.md) | The laptop is the only caller trusted without a password |
| [5](0005-cached-readings.md) | Demo photos are answered from a cache, and the evaluation never uses it |
